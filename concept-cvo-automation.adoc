= Saiba mais sobre as opções de automação do Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
As equipes de DevOps usam diversas ferramentas para automatizar a configuração e a administração de seus ambientes de runtime de data center. Além do NetApp Console, você pode usar várias dessas tecnologias para a automação do Cloud Volumes ONTAP, incluindo as APIs do NetApp Console, procedimentos da CLI do ONTAP e ferramentas de automação, como Ansible e Terraform. As ferramentas de automação externas geralmente são baseadas em um projeto de Infrastructure as Code (IaC).

Use https://labondemand.netapp.com/["O Lab on Demand"^] para praticar a automação do Cloud Volumes ONTAP.



[[netapp-console-apis]]
== APIs do NetApp Console

A NetApp Console fornece APIs REST que você pode usar para administrar programaticamente os recursos do Cloud Volumes ONTAP. As APIs oferecem suporte a operações como criar e administrar sistemas do Cloud Volumes ONTAP e adicionar agregados e volumes no Amazon Web Services (AWS), Microsoft Azure (Azure) e Google Cloud. As chamadas de API disponíveis variam de acordo com o provedor de nuvem e o tipo de implantação, incluindo configurações de nó único e de alta disponibilidade (HA).

Você pode usar os fluxos de trabalho da API do Cloud Volumes ONTAP para automatizar uma implantação típica e a administração subsequente de storage. Alguns fluxos de trabalho incluem a preparação para a implantação, a criação de um sistema e a administração do storage, com fluxos de trabalho específicos do provedor para AWS, Azure e Google Cloud.

Você pode usar a ONTAP CLI para várias tarefas de administração do Cloud Volumes ONTAP. Os procedimentos e comandos disponíveis variam de acordo com o recurso e o provedor de nuvem. Não use a ONTAP CLI nem o ONTAP System Manager para atualizar o Cloud Volumes ONTAP. Realize as atualizações a partir do NetApp Console.

[[terraform]]
== O Terraform

O Terraform é uma ferramenta de orquestração de código aberto que usa arquivos de configuração declarativos. NetApp fornece um provedor do Terraform para o Cloud Volumes ONTAP. Você pode usá-lo para automatizar e integrar sua infraestrutura com IaC. Para obter mais informações, consulte  https://registry.terraform.io/providers/NetApp/netapp-cloudmanager/latest["Provedor Terraform da NetApp"^].
